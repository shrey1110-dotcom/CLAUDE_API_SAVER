# Security Policy

## Supported versions

Security fixes are applied to the latest released version of ScopeKit and the
current `clean-main` branch. Older releases may not receive security updates.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Instead, use
GitHub's private vulnerability reporting form:

https://github.com/shrey1110-dotcom/ScopeKit/security/advisories/new

Include the affected version, reproduction steps, expected impact, and any
suggested mitigation. Remove secrets, access tokens, and personal data from the
report.

The maintainers will acknowledge the report, investigate it, and coordinate a
fix and disclosure when appropriate. Please allow time for a patch before
sharing vulnerability details publicly.
