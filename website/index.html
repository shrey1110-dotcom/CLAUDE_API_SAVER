Published on npm · CLI-first

Task-complete context packs for AI coding agents.

ScopeKit gives Claude, Codex, Cursor, and MCP clients the files, symbols, tests, relationships, risks, and validation commands they need for a specific task.

The right files, not a graph to wander.

npm install -g scopekit
scopekit setup

No global install: npx scopekit setup

Setup writes repo-local instructions for Claude, Codex, and Cursor. It does not install anything into your AI account.

  • Published on npm
  • 5/5 Codex quality wins
  • 5/5 Claude equal-or-better quality
  • 0 external LLM indexing required by ScopeKit

Install in one command.

Global install

npm install -g scopekit
scopekit setup

Or run without installing

npx scopekit setup

scopekit setup creates repo-local instruction files:

  • CLAUDE.md
  • AGENTS.md
  • .cursor/rules/scopekit.mdc
  • .scopekit/mcp-config.example.json

For remote or cloud agents, commit those files so the agent can see them.

Index, pack, query.

Three commands cover the common loop.

scopekit index .
scopekit pack "Find auth/session logic" --profile claude
scopekit query "Where is auth handled?"
scopekit pack "Plan a safe edit" --profile ultra
default
Balanced pack.
ultra
Smallest packs for Codex-style workflows.
claude
Richer relationships and risks for Claude and Cursor.

What ScopeKit does

Finds the relevant files.

ScopeKit ranks files and symbols for the task instead of dumping the whole repo.

Adds relationships.

It includes why files matter together: imports, tests, entrypoints, risks, and validation commands.

Fits the assistant.

Use --profile ultra for smaller Codex packs or --profile claude for richer Claude and Cursor packs.

Keeps MCP optional.

The CLI workflow works everywhere. MCP is available when a client wants live tool access.

Benchmarks

Scoped to this repo, these tasks, and these clients. Not universal superiority claims.

Codex — supplied context

Across a 5-task Codex supplied-context benchmark, ScopeKit produced ~94% smaller supplied context than Graphify best-effort, achieved equal-or-better quality on 5/5 tasks, and lowered median Codex usage on 5/5 tasks.

Claude — supplied context

Across a 5-task Claude supplied-context benchmark in Cursor, ScopeKit's Claude profile produced 79–88% smaller supplied context than Graphify-derived context, with equal-or-better quality on 5/5 tasks. Exact Claude token usage was not available from Cursor, so no Claude token-savings claim is made.

MCP locked-mode

Scoped Codex locked-mode MCP proofs showed:

  • 80.0% mean reduction on auth-discovery
  • 94.3% mean reduction on impact-analysis

These are scoped benchmarks, not universal superiority claims.

Context packs vs knowledge graphs.

Graphify builds a persistent graph to explore a codebase. ScopeKit builds a small task packet for the moment an agent needs to act.

Graphify

  • Queryable knowledge graph
  • Graph visualization and reports
  • Multi-modal graph extraction
  • Good for exploring system structure

ScopeKit

  • Task-specific context pack
  • Client-specific profiles
  • No external LLM indexing required
  • Good for the smallest useful packet before an agent edits or reasons

Use a graph when you want to explore. Use a context pack when the agent needs to do the task.

FAQ

Is ScopeKit a Graphify replacement?

No. Graphify builds a queryable graph for exploring a codebase. ScopeKit builds a small task pack for the moment an agent acts. They solve different problems.

Does ScopeKit require an API key?

No. Local indexing and packing need no API key and no external service.

Does ScopeKit send code to an LLM?

No. Indexing and packing run locally. ScopeKit does not send your code to an LLM to build packs.

Does it work without MCP?

Yes. The CLI workflow is the default. MCP is optional for clients that want live tools.

Does scopekit setup install a skill into Claude or Codex accounts?

No. It writes repo-local instruction files. It does not install anything globally into your Claude or Codex account.

How do I use it with remote or cloud agents?

Run scopekit setup, then commit the generated instruction files so the remote agent can read them.

Can I still use repo-context?

Yes. The repo-context and repo-context-mcp commands still work as deprecated aliases. New setups should use scopekit.

What claims are proven?

The scoped benchmarks above: smaller supplied context and equal-or-better quality on the measured Codex and Claude tasks, and the locked-mode MCP reductions on auth-discovery and impact-analysis.

What claims are not proven?

Universal superiority over Graphify, guaranteed token savings on every task, and Claude token savings (exact Claude usage was not available from Cursor).
