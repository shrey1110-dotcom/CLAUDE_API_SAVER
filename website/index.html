Task-complete repo context for AI coding agents.

repo-context gives Codex, Cursor, Claude, and other coding agents tiny task-specific packs of the exact files and symbols they need — without making them wander through a graph.

The right files, not a graph to wander.

Graph tools make agents search for the right subgraph. repo-context gives them the task-ready context directly: files, symbols, and why each one matters.

Graph-first workflow

  • Build graph
  • Query graph
  • Hope retrieval lands on the right files
  • Send larger context to the model

repo-context workflow

  • Index repo locally
  • Generate task pack
  • Send exact files and symbols
  • Keep context small and task-complete

Benchmarked against Graphify best-effort retrieval.

In a scoped 5-task repo-understanding benchmark using Codex CLI with supplied context and no MCP tools, repo-context produced smaller context, equal or better quality, and lower median Codex usage on every completed task.

A bigger compression profile.

~1,280×

Graphify advertises 71.5× reduction versus naive full-context reading. repo-context produced about 18× smaller median supplied context than Graphify best-effort in our benchmark. Using the same baseline style, that corresponds to a ~1,280× baseline-equivalent context-compression profile.

This is a context-compression comparison, not a universal end-to-end token claim.
