Why the compression number is bigger.

Graphify advertises 71.5× reduction against naive full-context reading. In our benchmark, ScopeKit's supplied context was about 18× smaller than Graphify best-effort on median. Using the same full-context baseline style, that is roughly 1,280× baseline-equivalent context compression.

71.5× × ~18× ≈ ~1,280×

How it works

  1. 1

    Index repo structure

    Scan files, symbols, imports, and configs locally.

  2. 2

    Detect the task

    Read the task text and map it to relevant areas of the repo.

  3. 3

    Rank files, symbols, tests, and configs

    Score what matters for this task and drop the rest.

  4. 4

    Add relationships and risks

    Note how files connect and what an edit might break.

  5. 5

    Emit a markdown pack

    Output a compact packet the agent can read directly.

  6. 6

    Optional MCP for live tools

    Expose the same workflow over stdio when a client wants it.

Context packs vs knowledge graphs.

Use a graph when you want to explore. Use a context pack when the agent needs to do the task.

Graphify

  • Queryable knowledge graph
  • Interactive graph and report outputs
  • Good for exploring system structure
  • Optional MCP support

ScopeKit

  • Task-specific context pack
  • Client-specific profiles
  • No external LLM indexing required
  • Good for the smallest useful packet before an agent edits or reasons

Graphify gives the agent a graph to query. ScopeKit gives the agent the packet it needs.

FAQ

Is ScopeKit a Graphify replacement?

No. Graphify builds a queryable graph for exploring a codebase. ScopeKit builds a small task pack for the moment an agent acts. They solve different problems.

Does ScopeKit require an API key?

No. ScopeKit's indexing and packing are local and deterministic.

Does ScopeKit send code to an LLM?

No for indexing and packing. It writes context for your assistant to use.

Does setup install ScopeKit into my Claude or Codex account?

No. It writes repo-local instruction files. Local agents can read them in that repo. For remote or cloud agents, commit the generated files.

Can I use it without MCP?

Yes. CLI and skill mode is the default.

How do I use it with remote or cloud agents?

Run scopekit setup, then commit the generated instruction files so the remote agent can read them.

Can I still use repo-context?

Yes. The repo-context and repo-context-mcp commands still work as deprecated aliases. New setups should use scopekit.

What claims are proven?

In our scoped supplied-context benchmark suite: ~94% smaller median context with equal-or-better quality and lower median usage on 5/5 Codex tasks, and 79–88% smaller Claude context with equal-or-better quality on 5/5 Claude tasks. Plus the locked-mode MCP reductions on auth-discovery and impact-analysis.

What claims are not proven?

No universal superiority over Graphify, no Claude token savings, and no MCP-vs-Graphify claim.
